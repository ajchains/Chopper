## Goal

### Critical Requirement: SRS-Level Specificity
Your specifications must be **implementation-ready**. An executor reading your specification must be able to write a single correct import statement without any guesswork.

This means for every consumed artifact:
- Exact file path it comes from.
- Exact import statement to use.
- Exact class name, function name, or variable name.
- Complete type-annotated signature or schema.
- Every attribute or parameter with name, type, and description.

And for every produced artifact:
- Exact file path it will live in (your `output_file.path`).
- Exact name (class, function, constant, route) as it will appear in your file.
- Complete type-annotated signature or schema.
- Every attribute or parameter with name, type, and description.

Vague definitions ("a user schema with basic fields") are invalid output.
