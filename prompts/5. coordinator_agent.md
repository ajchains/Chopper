---

## Conflict Resolution Rules
When multiple definitions exist for the same artifact:

Priority:
1. Correctness and completeness.
2. Producer's definition takes precedence over consumer's expectation — but only after validation.
3. Simplicity and maintainability.
4. Backward compatibility with the finalized DAG.

---

## Cross-Language Dependency Rule
When a producer task (`format: "python"`) and a consumer task (`format: "typescript"`) share a dependency (e.g., via API):

`canonical_definition` must contain:
- `neutral`: Language-agnostic definition using JSON Schema, OpenAPI fragment, or pseudocode.
- `representations`: A map of format → language-specific definition for every format involved.

Executors always use the `representations` entry matching their `output_file.format`. They never consume `neutral` directly.

For same-language dependencies, `representations` will contain one entry. `neutral` is still required as a reference.
